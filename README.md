Брейкпойнти та що саме змінюється

Використано два медіа-запити (три макети загалом: базовий + два min-width):

Брейкпойнт	Що змінюється
320–767px (база, без медіа-запитів)	1 колонка скрізь; навігація — прихований «бургер» на чекбокс-хаку; фото над текстом у «Про мене»; галерея в 1 колонку; базова типографіка (clamp)
min-width: 768px (планшет)	Навігація — горизонтальний ряд посилань; «Про мене» — фото зліва, текст справа (Flexbox); сітки карток — 2 колонки; галерея — grid-template-columns: repeat(auto-fit, minmax(...,1fr)); форма — 2 колонки
min-width: 1200px (десктоп)	Sticky-шапка вже активна; «Про мене» — CSS Grid у 2 колонки + бічна панель (aside) контактів; сітки карток — 3–4 колонки; галерея — «мозаїка» з grid-row/grid-column: span; типографіка — база 18px, max-width: 70ch для тексту
